# Поток — персональные финансы

Готовое одностраничное приложение на HTML, CSS и Vanilla JavaScript. Без сборки, базы на сервере, регистрации и аналитических трекеров. Валюта — российский рубль. Деньги хранятся целыми копейками; выражения рассчитываются без `eval`.

## Быстрый старт

1. Откройте приложение через HTTPS или локальный веб-сервер.
2. В «Обзор → Мои счета → Управлять» укажите начальные остатки. На телефоне настройки доступны через шестеренку вверху.
3. Запишите первую операцию. Можно ввести `350 + 120`, `1000 / 3` или `(250 + 150) * 2`.
4. Добавьте регулярные платежи и цели в «Планы». При оплате подписки нажмите «Оплатить» — приложение не списывает реальные деньги и не делает автоматических проводок.
5. Регулярно скачивайте JSON в настройках.

Кнопка «Демоданные» включает отдельную временную базу с вымышленными цифрами. Ваши записи сохраняются отдельно. Выход и перезагрузка возвращают собственную базу.

## GitHub Pages

1. Создайте репозиторий и загрузите **содержимое этой папки** в корень ветки `main`.
2. В GitHub откройте Settings → Pages → Deploy from a branch → `main` → `/ (root)` → Save.
3. Откройте выданный GitHub адрес по HTTPS. Все пути относительные: приложение работает и по адресу `https://username.github.io/repository/`.
4. Для установки на Android выберите в меню браузера «Установить приложение». На iPhone в Safari: «Поделиться» → «На экран Домой».

GitHub Pages не требует `npm`, сборщика или настроек сервера. `.nojekyll` исключает ненужную обработку файлов.

Для локального запуска, если установлен Python:

```sh
python3 -m http.server 8000
```

Откройте `http://localhost:8000`. Открытие `index.html` двойным щелчком через `file://` не поддерживается: ES-модули и PWA требуют HTTP/HTTPS.

## Что умеет

- Быстрая запись доходов, расходов и переводов с калькулятором, датой, заметкой и запоминаемыми тегами.
- Несколько счетов с отдельными остатками; категории и счета можно добавлять и переименовывать.
- Контуры «Личное» и «Дело». Баланс фильтруется по принадлежности счета; доходы и расходы — по контуру операции. Рабочую покупку можно оплатить личной картой.
- Дневной бюджет с резервом на регулярные платежи и общим месячным лимитом.
- Подписки, накопительные цели, книга долгов и погашение в один шаг.
- Диаграммы Chart.js, доля сохраненного дохода, сравнение шести месяцев.
- Поиск и фильтры по истории, редактирование и удаление операций.
- Экспорт всей базы в JSON, проверяемый импорт с подтверждением замены, CSV с текущими фильтрами для Excel.
- PWA с иконками, ярлыками быстрого запуска и офлайн-кэшем.

## Как считаются деньги

Баланс счета = начальный остаток + доходы − расходы − переводы со счета + переводы на счет − пополнения целей. Операции с будущей датой не меняют доступный баланс до наступления этой даты. Переводы и пополнения целей не участвуют в доходах/расходах и Savings Rate.

Дневной бюджет = `max(0, доступный баланс − резерв) / дни до конца месяца`, с округлением вниз до копейки. Текущий день включен. Если задан месячный лимит, для контура «Все финансы» применяется меньшая из двух сумм: доступные деньги и остаток лимита после фактических расходов; из нее также вычитается резерв. Для отдельных контуров общий лимит не применяется. Период графиков не меняет дневной бюджет текущего месяца.

Резерв — сумма еще не оплаченных регулярных платежей текущего месяца. Просроченный платеж остается в резерве до конца месяца. Операция, записанная кнопкой «Оплатить», снимает соответствующий резерв. При ручной записи платеж также распознается по счету, точной сумме и названию подписки в заметке. Для 29–31 числа в коротком месяце выбирается последний день.

Пополнение цели создает связанную операцию и уменьшает баланс счета. Накопленная сумма второй раз не вычитается. При удалении пополнения деньги возвращаются на счет. Изменение суммы корректирует копилку. Для удаления цели сначала удалите ее пополнения.

Создание долга — запись обязательства: оно не меняет баланс и не отражает первоначальную выдачу/получение денег автоматически. Если это нужно, внесите такую операцию отдельно. «Мне должны → Погашено» создает доход, «Я должен → Погашено» — расход. Изменение операции погашения обновляет связанный долг; удаление снова открывает его.

## Данные и приватность

Данные сохраняются в `localStorage` под ключом `potok.finance.v1`. Предыдущее состояние — в `potok.finance.v1.backup`. При повреждении основной копии приложение пытается открыть резервную. При недоступности хранилища или переполнении оно показывает ошибку и не сообщает об успешном сохранении.

База привязана к **адресу сайта и браузеру**. Локальный запуск, GitHub Pages и размещенная версия имеют отдельные базы. Для переноса используйте экспорт/импорт JSON. Очистка браузера, приватный режим или потеря устройства могут удалить записи. Хранилище не зашифровано.

Приложение не отправляет финансовые записи на сервер. Для первого подключения Chart.js и Lucide браузер обращается к CDN; затем Service Worker пытается кэшировать библиотеки. Если CDN недоступен, локальные SVG-иконки и резервные представления диаграмм сохраняют работоспособность. Полноценные графики Chart.js доступны после успешной загрузки библиотеки.

Офлайн-режим требует хотя бы одного успешного запуска онлайн и завершения установки Service Worker. Установка PWA зависит от браузера; встроенный браузер некоторых приложений может не поддерживать ее. Предпочтительны актуальные Chrome/Edge на Android и Safari на iOS.

## Структура

```text
index.html      оболочка приложения
styles.css      адаптивный интерфейс
app.js          экраны, взаимодействия, сохранение, импорт/экспорт
finance.js      финансовая логика и проверка данных
manifest.json   конфигурация установки PWA
sw.js           кэш статики и работа без сети
icon.svg        значок сайта
icons/          PNG-иконки PWA и maskable-иконка
```

При выпуске изменений повышайте версию `CACHE` в `sw.js`: это обновит кэш и удалит предыдущие версии после активации. Новая версия интерфейса загрузится при следующем открытии/перезагрузке.

Используются [Chart.js](https://www.chartjs.org/docs/latest/) и [Lucide](https://lucide.dev/), распространяемые по MIT. Документация [Service Worker](https://developer.mozilla.org/en-US/docs/Web/API/Service_Worker_API/Using_Service_Workers).
